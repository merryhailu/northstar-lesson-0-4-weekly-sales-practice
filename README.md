# Weekly Sales Summary

This project was built in a Jupyter Notebook as part of Lesson 0.4 in Coding Temple’s AI Data Analytics Foundations course.

# What It Does

The notebook works with fictional weekly sales data and performs basic data analysis tasks such as:

-Calculating total sales
-Finding the number of sales entries
-Identifying maximum and minimum sales values
-Creating a DataFrame using Pandas for better data visualization

# How to Run

Requirements
-Python 3.10 or higher
-Anaconda
-VS Code
Required libraries:
-Pandas
-NumPy

# Setup

1.Install Anaconda
2.Open the project in VS Code
3.Install required libraries - pandas
pip install pandas  
4.Open and run the Jupyter Notebook
